# Hayatın Anlamı Abi Sayacı

## Dünyanın En Önemli Projesi (Değil)

Bu repository, insanlık tarihinin en büyük gizemini çözmek üzere tasarlanmıştır: **Hayatın anlamı nedir?**

Cevap: Abi.

Daha doğrusu, 'abi' kelimesini yeterince söyleyerek ve rastgele absürt cümleler üreterek. Bilim camiası henüz onaylamadı ama biz onayladık. Çünkü abi dedi.

### Nasıl Çalıştırılır?

```bash
python3 abi_sayaci.py
```

Sonsuza kadar çalışır. Durdurmak için Ctrl+C. O zaman da "Abi pes etti" der. Ciddiye almayın, ama alın çünkü çalışıyor.

### Özellikler

- Gerçekten çalışır (Python 3 ile).
- Rastgele Türkçe absürt anlamlar üretir.
- Yorgun abi simülasyonu içerir (sleep var).
- Hiçbir şey çözmez ama güldürür.
- Gizli mesajlar içerir (aramayın, bulamazsınız, veya bulursunuz).

### Neden Bu Proje?

Çünkü aklıma geldi. Anlamlı olması gerekmiyordu. Türkçe olsun yeter. Patates yok, söz.
